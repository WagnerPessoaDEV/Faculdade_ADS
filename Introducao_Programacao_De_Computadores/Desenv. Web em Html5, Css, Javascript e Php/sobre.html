2. Arquitetura das 4 Camadas Web

🌐 HTML5 Estrutural

Estruturação semântica com páginas dedicadas: index.html (Landing), cadastro.html (Formulário completo) e sobre.html.

🎨 CSS3 Estilizado

Estilização pura no arquivo css/style.css com variáveis globais, design system coeso, Flexbox, CSS Grid e total responsividade para dispositivos móveis.

⚡ JavaScript ES6+

Implementado em js/main.js contendo máscara dinâmica de telefone e CPF, cálculo algorítmico do dígito verificador do CPF, contador de caracteres e filtro de busca instantâneo na tabela.

🐘 PHP 8+ & PDO

Processamento em processa_cadastro.php e listar.php com sanitização estrita, prevenção contra XSS e SQL Injection com Prepared Statements e persistência em banco relacional SQLite.

3. Decisões de Engenharia de Software

Como estudante do 2º período de ADS, o projeto foi concebido priorizando a portabilidade imediata, a experiência de uso (tema claro/escuro persistente e pré-visualização instantânea de foto) e a segurança em camadas. A utilização do driver SQLite via PDO dispensa qualquer necessidade de importação manual de scripts SQL ou configuração prévia de credenciais de banco de dados por parte da professora: ao rodar o projeto, a base database.sqlite e a tabela relacional são criadas de forma totalmente transparente e automática.
